# 法楽寺 肖像画像の権利・来歴管理

公開する修復前・修復後の肖像画像と解説画像には次の三層を併用しています。法楽寺版では写実肖像画を公開しません。

1. 秘密鍵で配置を決める反復DCT不可視ウォーターマーク
2. Copyright、Creator、Credit、Source、Rights Usage Terms、Asset ID のメタデータ
3. 無加工マスターのローカル保管と、公開前後のSHA-256台帳

表示上の権利表記は `© 2026 大和高山 法楽寺` です。これは画像の管理主体と出所を示すためのもので、個々の画像について著作権が成立するかどうかを単独で確定するものではありません。

## 重要な運用事項

- `.rights-masters/` と `.rights-private/watermark.key` はGit管理外です。外部の暗号化媒体にも複製して保管してください。
- 秘密鍵を失うと不可視ウォーターマークを照合できません。鍵を公開すると第三者による偽装や除去が容易になります。
- SNS、スクリーンショット、大幅な切り抜き・縮小・再圧縮では、メタデータまたは不可視情報が失われる場合があります。
- 公開済みGit履歴にある過去の無加工画像は、この処理では削除されません。
- 台帳は `rights/asset-manifest.json` です。公開ファイルを更新した場合は再処理し、新しい台帳を保存してください。
